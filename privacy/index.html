개인정보 처리방침

스킨코치 (SkinCoach) · 시행일: 2026년 4월 1일 · v1.2

스킨코치는 사용자의 피부 데이터를 기기 내부에 우선 저장합니다. 카카오/Apple 로그인 시 일부 정보가 국외 서버에 암호화 전송됩니다. 게스트 모드에서는 국외 이전이 발생하지 않습니다.

1. 수집하는 개인정보 항목

앱 사용 시 직접 입력

  • 필수: 피부 타입, 피부 고민, 민감도, 스킨케어 목표
  • 선택: 보유 제품 목록, 일일 피부 체크인, 루틴 완료 이력, 생리주기 정보

카카오 로그인 사용 시

  • 카카오 계정 고유 ID, 닉네임 (선택), 이메일 (선택)

Apple 로그인 사용 시

  • Apple 계정 고유 ID (User Identifier), 이름 (최초 1회), 이메일 (선택·릴레이 주소 포함)

자동 수집

  • 앱 사용 세션 정보, 기기 모델·OS 버전

2. 개인정보 수집 및 이용 목적

  • 맞춤 스킨케어 루틴 생성 및 제품 추천
  • 피부 상태 변화 이력 추적 및 리포트 제공
  • 기기 간 데이터 동기화 (로그인 사용 시)
  • 앱 서비스 개선 및 오류 분석

3. 개인정보 보유 및 이용 기간

  • 기기 내 데이터: 앱 삭제 또는 회원 탈퇴 시까지
  • 소셜 로그인 연동 서버 데이터: 회원 탈퇴 요청 즉시 삭제
  • 관계 법령에 따른 보존 필요 시 해당 기간 동안 보관

4. 개인정보 제3자 제공

스킨코치는 원칙적으로 사용자의 개인정보를 외부에 제공하지 않습니다. 다음의 경우에만 예외입니다.

  • 사용자가 사전에 동의한 경우
  • 법령에 의거하거나 수사기관의 요청이 있는 경우

AI 분석 기능 관련: AI 성분 분석 사용 시 Anthropic API(Claude)에 제품 성분 정보가 전송됩니다. 이때 개인 식별 정보는 포함되지 않습니다.

로그인 서비스 관련: 카카오 로그인은 Kakao Corp., Apple 로그인은 Apple Inc.의 인증 서비스를 통해 이루어집니다.

5. 개인정보의 국외 이전

스킨코치는 서비스 제공을 위해 아래 업체에 개인정보를 국외로 이전합니다.

Supabase Inc.

  • 이전 국가: 일본 (AWS ap-northeast-1, 도쿄)
  • 이전 항목: 계정 ID, 루틴 데이터, 피부 프로필 (로그인 사용자에 한함)
  • 이전 목적: 클라우드 데이터베이스 저장 및 인증 서비스 제공
  • 보유 기간: 서비스 탈퇴 요청 시까지
  • 문의: privacy@supabase.io

Anthropic PBC

  • 이전 국가: 미국
  • 이전 항목: 제품 성분 정보 (개인 식별 정보 미포함)
  • 이전 목적: AI 성분 분석 기능 제공 (사용자가 기능 실행 시에만 전송)
  • 보유 기간: API 호출 처리 후 즉시 파기 (Anthropic 정책 기준)
  • 문의: privacy@anthropic.com

국외 이전에 동의하지 않을 경우 소셜 로그인 및 AI 분석 기능을 이용할 수 없습니다. 게스트 모드에서는 국외 이전이 발생하지 않습니다.

6. 만 14세 미만 이용자 처리

스킨코치는 만 14세 미만 아동의 개인정보를 원칙적으로 수집하지 않습니다.

  • 회원가입(카카오/Apple 로그인) 시 만 14세 이상임을 확인합니다.
  • 만 14세 미만임이 확인된 경우 즉시 회원 탈퇴 처리 및 수집된 정보를 삭제합니다.
  • 법정대리인의 동의가 확인된 경우에만 서비스 이용이 가능합니다.

관련 문의: medix.ai.team@gmail.com

7. 개인정보 보호를 위한 기술적 조치

  • 피부 프로필, 루틴 기록 등 민감 데이터는 기기 로컬(SQLite)에 저장
  • 생리주기 데이터는 온디바이스 우선 저장, 서버 동기화 시 HTTPS 암호화 전송
  • Apple 로그인 자격증명은 iOS Keychain에 안전하게 보관
  • 카카오/Apple 로그인은 OAuth 2.0 / Sign in with Apple 표준 프로토콜 사용
  • 서버 통신에 TLS 1.2 이상 사용
  • 앱 데이터는 외부에 자동 전송되지 않습니다.
사용하지 않는 권한: 카메라, 사진 라이브러리, 위치 정보, 연락처, 마이크, 광고 추적(ATT)

8. 사용자의 권리 및 행사 방법

사용자는 언제든지 다음의 권리를 행사할 수 있습니다.

  • 개인정보 열람 요청
  • 개인정보 수정·삭제 요청
  • 개인정보 처리 정지 요청
  • 동의 철회

앱 내 행사 방법

  • 마이페이지 → 프로파일 수정에서 직접 정보 변경
  • 마이페이지 → 회원탈퇴로 모든 데이터 즉시 삭제
  • 앱 삭제 시 기기 내 모든 데이터 자동 삭제
  • 카카오/Apple 로그아웃으로 소셜 연동 해제 가능
  • Apple 로그인 탈퇴 시 Apple 측 토큰 자동 폐기(revoke) 처리

위 방법으로 해결되지 않을 경우 medix.ai.team@gmail.com으로 문의 주시면 10영업일 이내 처리합니다.
